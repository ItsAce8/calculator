# Calculator

This is my Calculator project for The Odin Project Foundations course.

## About the Project

This project is a simple calculator made using HTML, CSS, and JavaScript.

The calculator can perform basic mathematical operations such as addition, subtraction, multiplication, and division. It also shows the current calculation on the display so the user can see the numbers and operator being entered.

I also added other features such as decimal numbers, a backspace button, keyboard support, chained calculations, and an error message when dividing by zero.

## What I Practiced

By completing this project, I practiced using JavaScript functions, variables, conditionals, and event listeners. I also practiced using the DOM to connect the calculator buttons to JavaScript and update the display based on the user's input.

I also practiced using CSS Grid to arrange the calculator buttons and improved my CSS skills by creating a simple blue design for the calculator.
